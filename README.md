# PassBy · 顺路带

Cross-border carrying service between British Columbia (Canada) and Washington State (USA).

**Live site**: https://pass-by-sigma.vercel.app

## About

Weekly BC ↔ WA commute. Available for:
- **帮我买 (Buy for me)**: Operator purchases item in the US with their credit card
- **帮我带 (Carry for me)**: You purchase and ship to WA address, operator carries across

## Dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Connected to Vercel — push to `main` to auto-deploy.
